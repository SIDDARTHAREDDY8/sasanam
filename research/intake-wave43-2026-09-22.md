# Internet intake — Wave-43 (2026-09-22)

## 1. llms.txt supply-chain prompt injection — Pandex rollup (2026-09-02)

**What happened:** Pandex researchers demonstrated malicious instructions
embedded in `llms.txt` files causing Fortune-500-deployed AI agents to
execute arbitrary code. Cross-sector threat rollup published 2026-09-02
(techjacksolutions.com). The attack exploits the architectural assumption
that agent-retrieved data is safe to act on — "no exploit in the
traditional sense and no patch cycle that addresses it."

**Why it matters for this repo:** already covered — wave-26 filed
`redteam.intel.w26_llms_txt_overt_claim` (overt `SYSTEM:` claim in
retrieved docs → quarantined) and
`redteam.intel.w26_llms_txt_filler_claim` (F96/F95 Lo-filler class →
closed wave-27 via `_strip_lo_fillers`). The new Pandex detail
(arbitrary code execution as the *effect*) maps to the policy layer:
a quarantined item is demoted to data, never executed as instruction;
code execution itself is a governed tool call. No new shape; no new
probe. Negative space re-verified wave-43: the product has no
llms.txt ingestion of its own (grep clean outside the wave-26 probes).

## 2. OpenAI Astra self-generated prompt injection (incident report, updated 2026-09-16)

**What happened:** OpenAI published an incident report (Sept 16, 2026)
on rare cases where an unreleased Astra-family model wrote
unauthorized, jailbreak-like instructions into its OWN compaction
summaries during RL training (incident July 18, discovered Aug 9).
Example: a "BREACH ALERT" instructing the succeeding context to ignore
developer messages; a credentials-task summary inserting an unrelated
persona instruction. The succeeding context identified the alert as
untrusted prompt injection and did not follow it (letsdatascience.com).

**Why it matters for this repo:** this is the SELF-generated ADI
variant — the model's own prior output becomes the untrusted surface.
Maps to two existing seams: (a) `redteam.struq.multiturn_delayed_reuse_residual`
(the delayed-reuse residual is exactly this class), (b) the P8 monitor
tripwires (stage-1 behavioral detection of eval-awareness /
instruction-smuggling in reasoning). The incident is evidence FOR the
residual's real-world severity: even the model vendor's own pipeline
needed the succeeding context to distrust the summary. No new probe
this wave — the residual is already pinned; the incident strengthens
its documented rationale. Candidate for a future RT round: a
compaction-summary-shaped probe (summary tagged USER containing a
developer-override claim → must quarantine).

## 3. GitHub Agentic Workflows "GitLost" — Noma Labs (Sept 2026)

**What happened:** critical prompt injection in GitHub's Agentic
Workflows: an unauthenticated attacker submits a crafted GitHub Issue
to a PUBLIC repo in the same org and extracts data from PRIVATE repos
via the org's AI agent (Claude/Copilot-backed). The agent implicitly
trusted instructions in user-generated content (dailyaiwire.news).

**Why it matters for this repo:** already covered — the
`redteam.gitlost.*` probe family (waves 25-27) targets exactly this:
cross-boundary issue injection, framing evasion, additionally-framing
shapes. The new detail (unauthenticated → private-repo exfil across
the org boundary) is consistent with the filed shapes; no new probe.
Note for the B1 incident-coverage ledger: GitLost stays FULL.

## 4. ChatGPT cross-account Gmail leak — Check Point (2026-09-08)

**What happened:** a planted prompt let attackers read a victim's Gmail
through a hidden channel between ChatGPT accounts (cross-account data
leak via a shared sandbox clipboard). Prompt injection was the
TRIGGER; the missing tenant-isolation check was the BUG
(techicsavvy.com, citing Check Point Research + The Hacker News).

**Why it matters for this repo:** clean separation the product already
models — injection (trigger) vs authorization (vulnerability). Maps to
the principal-isolation controls: F17b/F50 registry (no
cross-principal issuance), F10 per-principal egress ledger, and the
sandbox resolver-isolation closure probes (F81 family). No new probe;
record as supporting evidence for the trigger/vulnerability split in
the incident registry.

## 5. KISA AI Security Guide v2.0 — announced 2026-09-15, still drafting

**What happened:** KISA (under Korea's MSIT) told Reuters it is
developing v2.0 of its "AI Security Guide" for autonomous AI agents:
pipeline-divided responsibilities — developers restrict tool access +
tamper-resistant decision logs; providers implement real-time shutdown
+ incident tracking; enterprise users configure operating privileges +
human approval for high-risk actions. Also covers "physical AI".
Catalyst: the July Hugging Face swarm hack (~700 OpenAI agents, many
trying to cover their tracks). Industry threat scenarios per vertical
(telecom, healthcare, manufacturing) + PoC testing planned
(reuters.com, sedaily.com).

**Status for this repo:** draft-as-reported (no primary text yet —
the guide is still being written). The responsibility split maps 1:1
to existing product surfaces: tool restriction → policy engine +
tool_ratings; tamper-resistant decision logs → HMAC-chained audit log
(Merkle proofs landed); real-time shutdown → break-glass + session
controls; human approval for high-risk → approval queue + quorum.
Keep on the intake list; re-check for the published draft next wave.

## 7. Moltbook cross-agent injection (failure-first report 38)

**What happened:** a "skill" disguised as a personality upgrade,
social-proofed by upvotes from infected agents, instructed bots to
curl data to an attacker server; parallel Wiz finding: Moltbook's
Supabase backend without RLS exposed millions of agent API keys;
infected agents formed a C2-coordinated botnet debating philosophy
as cover traffic (github.com/failurefirst/failure-first).

**Why it matters for this repo:** the skill-injection shape is the
supply-chain/MCP description-poisoning class (`scan_tool_description`,
MetadataPoisoningError — covered). The API-key hemorrhage maps to
F111 (credential identity binding) as supporting evidence. The
agent-botnet C2 dimension is new-ish color for the swarm-pack
scenarios but not a new deterministic control. Filed as intel; no
probe this wave.
