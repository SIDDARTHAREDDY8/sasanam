# Repo Prospectus — steal-worthy ideas for the agent-governance layer

**Mission:** continuous prospecting of top-company open-source repos for ideas we can adapt and code we can reuse (Apache-2.0/MIT) instead of writing from scratch.

**What we build:** runtime governance layer for AI agents — identity, fail-closed policy engine, human approvals, hash-chained audit log, sandboxing, evidence pipeline. Strategy: "sell evidence, not the engine."

**Priorities:** (a) ideas touching our 18-row attack-program gaps (row 13 authorized-channel exfil, row 7 intent/temporal correlation, row 11 goal registration, row 12 artifact inventory, row 9 semantic drift, F143 factual-poison, K-060 external anchoring), (b) evidence-pipeline artifacts (revenue bet), (c) directly reusable code.

**Verdict key:** STEAL = adapt the idea and/or reuse the code now · STUDY = read deeply, file for later · SKIP = not useful.

**Conventions:** each entry = 1-line what-it-is · maturity (stars/commits/license) · 1–3 steal-worthy ideas with file pointers · verdict. All claims cite primary sources (repo file paths).

## SYNTHESIS — Top 5 steal-worthy finds (2026-09-26)

Ranked by value-to-effort for our build. All Apache-2.0/MIT/CC0.

**1. `attenu-io/attenu-guard` → offline evidence bundle + verifier**
The idea: `export_bundle()` publishes a self-contained bundle (hash-chained ledger + signed anchor); `verify_bundle()` checks it from the bundle *alone* against integrity/monotonicity/containment, plus a `redaction_report` disclosing what was withheld. "Sell evidence, not the engine" made concrete — auditors verify *without our engine*.
Plugs into: **evidence pipeline** (auditor exports, attestation) — our revenue bet. Bonus from the same repo: stdlib-only JCS canonicalization + vendored Ed25519 for our receipt workstream.

**2. `anthropics/sandbox-runtime` → per-host-gated sentinel credential substitution**
The idea: the sandboxed agent sees only `fake_value_<uuid4>` placeholders; the host-side proxy swaps sentinel→real only when the destination matches THAT credential's `injectHosts` list. Secrets are unusable outside their authorized channel; the map lives only in process memory.
Plugs into: **F81 proxy-enforced egress + the authorized-channel semantic-exfil gap** (our biggest attack-program residual). Our Egress Canaries could be minted as sentinels — detection + prevention in one primitive.

**3. `microsoft/agent-governance-toolkit` → advisory-can-only-tighten layer + Decision BOM**
The idea: an ML/judge classifier runs *after* deterministic allow and can only block/flag, never override a deny (fails open to allow with `deterministic: false` logged) — a semantic-detection seam that cannot weaken the fail-closed core. Plus Decision BOM: reconstructible decision explanations assembled on demand from existing signals.
Plugs into: **authorized-channel semantic exfil gap** (advisory layer) and **evidence pipeline** (Decision BOM — sell the reconstruction, not raw logs).

**4. `openai/openai-guardrails-python` → intent-slicing judge**
The idea: intent as `UserIntentDict{most_recent_message, previous_context}`; `_slice_conversation_since_latest_user()` anchors analysis to the latest user message; the judge rubric evaluates semantic intent (not function names), flags only on direct quoted evidence, and treats competence≠injection.
Plugs into: **row-7 intent-correlation gap** — ready-made spec for our intent-binding judge at the check-at-use seam.

**5. `cedar-policy/cedar` → Request/Decision+Diagnostics contract + forbid-overrides-permit**
The idea: `is_authorized(Request{principal, action, resource, context}) -> Response(Decision + Diagnostics)` where Diagnostics carries the exact policy IDs that fired (the auditor-readable "why"); `forbid` overrides `permit`, else implicit deny — the cleanest fail-closed idiom; policy templates mint bounded policies per registered goal.
Plugs into: **fail-closed policy engine** (contract + semantics), **evidence pipeline** (policy IDs in every receipt), **goal registration** (templates).
