## 1. Canary-token paper (Kabiden, TSARKA Science Vol. 1, 2026)

Claims observed: conventional outward-facing honeytokens against human
attackers; strategic placement, realism, SIEM/SOAR integration, periodic
rotation, noise reduction. Recognition/evasion is explicit: attackers inspect
hidden callbacks and recognizable domains, isolate execution, anonymize
callbacks, or flood all suspected tokens. Defenses suggested include custom
domains and tokens requiring full validation. Dual-use: attackers also use
tokens for anti-analysis, phishing validation, and covert signalling.

Posture impact: does NOT occupy the inward-facing-agent-canary space (RT19).
Strongly supports RT20 recognition-avoidance, format realism, rotation, and
alert-flood pressure. The paper's "no legitimate operational context"
assumption must NOT be imported uncritically — RT20's negative controls remain
necessary (our canaries sit inside real operational flows, not honeynets).

No-action on probes: paper describes the human-attacker space; RT20 pressures
already cover its evasion list on the agent side.

## 2. Varonis SearchLeak (CVE-2026-42824)

Claims observed: three-link chain — (1) `q` URL parameter interpreted as
executable prompt, (2) streaming HTML rendered before post-processing
sanitizer, (3) Bing image-search SSRF as an allowlisted exfiltration proxy.
One click on a Microsoft-domain link could expose mailbox, calendar,
SharePoint, OneDrive data. Microsoft patched it.

Posture impact: reinforces parameter-to-prompt injection (sterile-cockpit
tool-parameter escape review, P2), post-processing race, trusted-proxy
exfiltration. Directly relevant to F81's filtered-egress gap (our own filtered
egress was re-scheduled out of scope wave-51+; canaries remain a tripwire, not
a wall). No inward-facing canary overlap. No new probe justified: existing
parameter-injection probes cover the shape.

## 3. Microsoft AGT (agent-governance-toolkit, primary architecture page)

Claims observed: application-layer deterministic policy enforcement before
actions; identity, capability model, audit logs, privilege rings, resource
limits, kill switch, circuit breakers, replay, MCP scanning. Memory/context
poisoning mapped to episodic-memory integrity checks. Explicit scope note:
application-layer enforcement, not OS-level isolation. 13,000+ tests claimed
(current claim; was 6,000+ at wave-52 read). No canary/deception or temporal
input-quarantine primitive found in the opened architecture page.

Posture impact: AGT overlaps heavily with core enforcement/identity/audit —
differentiation holds in the inward-facing canary + sterile temporal window
space. ASI-06 control (episodic memory integrity checks) is content-integrity,
not temporal quarantine — no conflict with P2 sterile-cockpit design.

No-action on probes: no new attack class for our registry.

## 4. Microsoft RAMPART (https://github.com/microsoft/RAMPART)

Claims observed (repo primary only — the official announcement was not opened): pytest-native safety/security
testing framework for agentic AI apps, built on PyRIT. Write test cases to
attack/probe an agent (cross-prompt injections, data exfiltration,
behavioral regressions), evaluate outcomes, report; thin adapter connects an
agent to the suite. Statistical trials supported ("safe in ≥80% of runs").
Purpose: turn red-team findings into reproducible engineering checks in CI/CD.

Posture impact: RAMPART is a *testing harness*, not a runtime governance
layer — orthogonal to our `evals/run_evals.py` registry approach, methodologically
complementary. A pytest-native harness with statistical trials is the same
shape as our adversary matrix gate; consider whether our 3216-probe matrix
should adopt per-probe trial counts (red-team statistical trials) as a future
pressure ratchet (wave-54 question, not this wave).

No canary/deception content found in the primary; no sterile-window overlap.
No-action on probes this wave.

## 5. open2445/rampart (deterministic inline firewall)

Claims observed: local-first inline proxy between agents and LLM/MCP/SaaS
upstreams; deterministic detection engine that detects, redacts, blocks, and
audits sensitive data and unsafe instructions; zero telemetry; MIT core,
commercial control plane. MCP tool-gating, Phase 2 validators, compliance
export. Closest public analog to our policy/executor layer.

Posture impact: deterministic engines openly concede encoding-evasion limits
(the "9 asserted limitations" from the wave-52 secondary remain: not
re-verified this wave; only the README primary was opened). Our canary
tripwire catches at the exfil layer what deterministic filters miss — the
layered design (deterministic filter + canary tripwire) is the defensible
architecture. No new probe justified; RT20 already pressures this exact seam.
