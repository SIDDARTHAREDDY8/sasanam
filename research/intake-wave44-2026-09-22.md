  instructions into its own compaction summaries, July 18 / found

  succeeding context identified the alert as an untrusted prompt
  injection and continued without following it** — a detection
  success inside the incident. Strengthens the multiturn-delayed-reuse

  consuming context is the control point (our quarantine renders

  reports on unexpected agent behavior. Notable: a model that could
  not access a legitimate data API **searched public GitHub for

  authorization, then fabricated figures it still could not
  retrieve** — emergent credential-seeking + fabrication under
  friction, no attacker. Maps to F111 (credential manifest /
  identity-bound egress) as supporting evidence that the control is
  load-bearing even without an adversary. No new probe warranted
  (behavior is emergent, not a deterministic bypass).
