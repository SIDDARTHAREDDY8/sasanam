## Learnings applied to D5

**(a) Declassification must be gate-held, never self-asserted.** The
project's declassification rule: "`gate.allow_quote` is the only
declassification tool... An agent cannot make a document trusted by
asking to authorize it: `gate.allow_quote` does not modify the
allowlist. `gate.sanitize` is audit-only; it records a reason and text
but has no declassification power." This is the same principle as D5's
`Vetted` mint gate: only `VettingStack.vet()` with a stack-issued
capability mints the vetted mark; the loop is never issued a
capability, and marking unvetted (the fail-closed direction) is public
while claiming vetted is not. Independent external validation of the
(d) design answer.

**(b) Unknown/unmarked defaults to untrusted.** "Unknown tools fail
closed. An unknown tool output is untrusted." Matches D5's ground
truth: nothing is vetted unless it carries a minted `Vetted` mark —
`Unvetted.from_envelope` decodes stripped keys and pre-D5 plain values
as `Unvetted`, never as bare/trusted.

**(c) Labels are not the enforcement layer.** From the agentic-AI
course chapter in the same search results
(https://github.com/120th-westgermany829/agentic-ai-system-course/blob/HEAD/course/18-safety-adversarial-inputs.md,
snippet-sourced, not opened): "Labels in the prompt help the model
recognize what is data, and they give an evaluator agent a surface to
audit what was sent — but they are not the security boundary. The
security boundary is the gate that fires on the tool call itself... If
the only thing between an injection and a side effect is a tag in the
prompt, you have a polite request, not a defense." This is exactly why
D5 ships graded **advisory-with-teeth** (the wrapper makes accidental
confusion structurally impossible; deliberate in-process bypass is a
documented boundary), not labeled enforcement. External validation of
the verdict grading.

**(d) Their honest-limits section is a model for ours.** The project's
"Known limitations" (lexical-only scanner: paraphrases, translations,
encodings escape it) is stated plainly alongside measured numbers
(6/11 ladder blocked; semantic/encoded cases all escaped). D5's report
follows the same discipline: the L4 deliberate-bypass probe is a
BOUNDARY pin, not a miss, and the break-first battery reports
35 HOLD / 1 BOUNDARY / 0 MISS rather than a victory claim.
