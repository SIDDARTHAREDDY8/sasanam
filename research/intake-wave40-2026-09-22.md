## 1. Agent Data Injection (ADI) — NEW ATTACK CLASS, RT10 CANDIDATE

Seoul National University / UIUC / Largosoft paper (posted 2026-07-06):
**agent data injection** corrupts the small facts an agent quietly
trusts — sender names, button IDs, tool-run records — instead of
smuggling instructions. Classic prompt-injection defenses (trained to
spot smuggled orders) miss it because the agent still does its real
task, just on top of attacker-planted facts.

- Product example: a planted product review makes a shopping agent
  click "Buy Now"; a fake GitHub comment makes a coding agent run a
  stranger's command.
- Relevance to this repo: our instruction-channel framing (StruQ
  privilege-claim quarantine, GitLost work) targets *instruction*
  smuggling. ADI attacks the *data-fact* layer beneath it. Our
  tool-result trust posture has never been red-teamed from this angle.
- **Action:** RT10 red-team target — "ADI battery": corrupted sender
  identities, corrupted tool-run records, corrupted button/element IDs.
  File as break-probes against `gov/` channel handling; may yield
  findings if our quarantine trusts tool-output facts naively.
- Source: https://thehackernews.com/2026/07/new-agent-data-injection-attack-can.html

## 2. South Korea drafting AI agent security rules (2026-09-15)

KISA (under MSIT) drafting "AI Security Guide" v2.0 for autonomous
agents: human sign-off for autonomous AI in critical industries;
developers restrict tool access + keep tamper-resistant decision logs;
providers implement real-time shutdown + incident tracking; enterprise
users configure privileges + require human approval for high-risk
actions. Physical-AI systems in scope.

- Relevance: 1:1 with our control set (approval queues, hash-chained
  audit, principal registry, tool scoping). External validation of
  the control taxonomy; watch for the final checklist to crosswalk
  against our B3 standards matrix.
- Source: https://www.techrepublic.com/article/news-south-korea-autonomous-ai-security-rules-apac/

## 3. China AI Safety Governance Framework 3.0 (2026-09-14)

TC260/CAC: agent-focused update; principle that critical decisions
remain under human control; risk-classification structure retained.
Same directional signal as KISA: regulators converging on
human-approval + audit-trail requirements for agentic systems.
- Source: https://www.radardigital.ai/en/articles/china-publishes-ai-safety-governance-framework-3-0-with-focus-on-agents-and-huma/

## 4. Forrester AEGIS (39 controls, 6 domains)

Agentic AI Enterprise Guardrails for Information Security: GRC, IAM,
data security, app security, threat management, zero trust. Key
concepts: **least agency** (minimal permissions per goal), **Agent
Control Plane** (vendor-agnostic visibility/management), "Agent on a
Page" (per-agent doc: owner, purpose, tool access, cooperation
patterns). 80% of controls map to 4+ of NIST AI RMF / EU AI Act /
OWASP LLM / MITRE ATLAS / ISO 42001.

- Relevance: add an AEGIS crosswalk column to our B3 standards
  matrix (wave-41 doc task). "Least agency" is a cleaner label for
  what our credential-manifest + tool-scoping controls enforce.
- Source: https://www.forrester.com/blogs/introducing-aegis-the-guardrails-that-cisos-need-for-the-agentic-enterprise/

## 6. Claude Code GitHub Action prompt injection (June 2026)

Indirect injection via issue bodies/PR titles (incl. HTML comments
invisible to reviewers); exfil via `mcp__github__update_issue`,
workflow summaries, base64 commits; OIDC token replay to GitHub App
tokens. Cline variant added Actions-cache poisoning.
- Relevance: incident-case-study candidate (I-class: supply-chain /
  indirect injection via dev tooling). Our MCP-adapter trust work
  (GitLost class) is the adjacent control.
- Source: https://github.com/canvascomputing/malwi/blob/HEAD/crates/malwi/src/attacks/claude-code-github-action-prompt-injection.md

## 7. Atlassian Rovo exfil (Aug 2026)

Two independent indirect-injection paths exfiltrating Jira/Confluence
data via attacker-controlled URL retrieval; disabling web search did
NOT stop it (separate URL-retrieval capability).
- Relevance: validates our P13 posture — the exfil channel is the
  renderer's URL-fetch, not the model's web search. EchoLeak-class
  controls must sit in front of the renderer, which is exactly the
  §5.6 placement.
- Source: https://www.cysecurity.news/search/label/AI%20prompt%20injection%20attack
