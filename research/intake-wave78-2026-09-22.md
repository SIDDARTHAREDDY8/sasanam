## Wave-78-relevant findings

### Plugin4Shell: post-disclosure facts (newer than the task brief)

- Disclosed 2026-09-17 by AIR Security (researchers Or Nevo, Dor Granat,
  Niv Hoffman); found May 2026, vendors privately notified June 2026 (~3
  months before public disclosure). The Register/Help Net Security covered
  at disclosure.
- Four agents confirmed vulnerable: Claude Code, OpenAI Codex, GitHub
  Copilot, Google Gemini CLI — all four checked out the pinned commit
  without verifying the checkout landed there. A branch named after the
  pinned 40-hex SHA is resolved by git *before* the commit object
  ("git prefers a ref over a commit of the same name"); the install
  reports the expected SHA while malicious code runs.
- Gemini CLI variant: a FETCH_HEAD-style branch name also works.
- Patch status (as of intake): **Anthropic patched Claude Code 2.1.179;
  OpenAI patched Codex 0.146.0.** Microsoft has shipped **no Copilot
  patch** (~90% of Fortune 500 use Copilot per Microsoft figures).
  Google **deprecated Gemini CLI without patching**; every existing
  install stays exposed indefinitely; users are directed to Antigravity
  (protected). The fix must ship in the agent — "no marketplace can
  fix," users must update.
- Blast radius from AIR's reporting: **925 plugins/skills hijacked in
  active use, reaching 134,000 agents** ("SkillJacking"); a prior AIR
  test plugin infected 26,000 agents before removal. AIR calls it "the
  first supply chain vulnerability of the AI agent ecosystem."
- GitHub-side mitigation (per a GitHub spokesperson): GitHub does not
  allow creating branch/tag names that resemble commit SHAs — host-side
  mitigation, does not cover self-hosted/Bitbucket/other hosts.
- No evidence of in-the-wild exploitation reported at disclosure.
- AIR's write-ups stress the ambient-authority amplifier: plugins run
  with the developer's permissions (source, API keys, env vars, SSH
  credentials, production systems) — a swapped plugin inherits all of
  it. This is the direct justification for the capability-lease half
  of wave-78.

### Capability-lease / JIT-credential convergence (independent
reinforcement of the design)

- The public playbook now says the same thing as this wave's Lane 1(e):
  agents get short-lived, task-scoped access minted at the execution
  boundary; durable secrets live in a vault/broker; the agent asks for
  a *capability*, not a raw credential (Medium/Toward Next AI,
  "AI Agent Credential Refresh"; dev.to/GitGuardian, "Your AI Agents
  Are Using Your Credentials").
- genai-security-project/agent-control-standard (identity standards):
  bearer tokens break under agents (memory, tool outputs, crash dumps
  are all token-leak surfaces; prompt injection exfiltrates tokens from
  working memory) → DPoP/mTLS-bound tokens; tokens must be short-lived
  and per-step; session-scoped credential isolation + memory-bound
  invalidation + per-action re-authorization. Wave-78's lease design
  (task-bound, use-time verification, no reuse across tasks, env
  free of raw credentials) matches this; DPoP/mTLS binding is a stated
  future direction, not claimed here.
- Descope (MCP auth): short-lived scoped credentials per task; scope
  per tool; MCP's structured step-up scope mechanism (2025-11-25 spec)
  is the incremental-scoping analog of our lease scope language.
- codecrux threat model: the exact `vault.lease(...)` pattern with
  TTL=60, "nothing written into an environment variable, memory, or
  prompt context. The credential is leased, used, and expired."

### Design implications taken into wave-78

1. The Plugin4Shell patch lesson ("verify the checkout landed") is
   *not* enough: pinning a reference is not pinning an artifact. The
   wave-78 gate pins digests only and refuses the ref namespace
   entirely (refname-shadowing is impossible when refs never enter the
   load path).
2. Two vendors patched, two didn't — the ecosystem will not fix
   itself, per the task brief. The governance layer must verify
   artifacts itself rather than trust host/agent behavior.
3. The lease design's public-convergence evidence goes in
   SUPPLYCHAIN_DESIGN.md §e (blast-radius claim) as independent
   support, not as a claim of novelty.

## Watch items (not wave-78 work)

- Copilot unpatched: enterprise plugin ecosystems on Copilot remain
  exposed; if the demo's threat model ever covers third-party coding
  agents, Copilot is the residual.
- Gemini CLI deprecated-without-patch: a precedent that "deprecated"
  ≠ "fixed" — retirements need the same verification treatment as
  patches (residual for a future decommissioning-hardening wave).
- GitHub's SHA-like-ref ban is host-side; self-hosted git servers are
  the residual. Our gate does not depend on host behavior.
