## Prior-art framing (from the standing memo, un-retrieved this wave)

- **authensor Sentinel:** commercial runtime monitor for agents;
  cited in the memo as the "standard pair" reference for EWMA-style
  spike detection. The wave-76 build treats the statistics as
  commoditized and differentiates on enforcement wiring + the
  anti-deception battery instead.
- **ACR framework (z > 2.5 / EWMA α = 0.3):** the memo's cited prior
  art for the exact spike parameters adopted (α = 0.3, z = 2.5,
  one-sided). Adopted verbatim as prior art, not invented.
- **Montgomery's CUSUM (k = 0.5σ / h = 5σ):** the textbook drift
  detector parameters adopted for the gradual-drift leg. Adopted
  verbatim as prior art.
- **Purpose-group cold start:** the memo's framing for assigning new
  identities to a conservative role-group default before personal
  baselines exist. The wave-76 implementation adds the adversarial
  twist the memo only implied: cold-start observations are evaluated
  but never trained on (attacker traffic cannot become the baseline
  by construction).
- **Harmful-direction filtering:** one-sided alerting (improvements
  never trip) per the memo; probed by
  `redteam.detection_w76.direction_of_badness`.
- **Greenblatt / Willison on monitor deception:** the memo's
  touchstone for the deceptive-agent threat model — an agent that
  knows it is monitored and shapes visible behavior (the HF
  grading-AI shape). The wave-76 anti-deception battery
  (`evals/w76_probes.py`) is built directly against this shape:
  threshold-edge gaming, monitor-blinding floods, cold-start
  poisoning, trip suppression, denial-storms — plus the two tripwires
  the agent cannot see coming (approval-side denial divergence, the
  anchor-downgrade latch).
- **OpenAI automatic monitoring:** cited in the memo as the industry
  direction (monitoring as a platform primitive). Wave-76's answer is
  the enforcement wiring: a trip is not a dashboard event, it
  downgrades live verdicts to `require_approval` (fail-closed) with
  no auto-reset.
